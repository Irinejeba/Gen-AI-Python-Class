# Gen-AI-Python-Class 🐍

My Python learning journey for Generative AI.

This repo contains all my class notes from Python basics to advanced topics.

## 📚 Topics Covered

- **Basics:** Variables, Data Types, Operators
- **Control Flow:** If-Else-Elif, Loops, Pattern Programs
- **Data Structures:** List, Set, Tuple, Dictionary
- **Functions:** Built-in Functions, User-Defined Functions, String Functions
- **Advanced:** Error Handling (Try-Except), File Handling
- **Practice:** Assignments, Interview Questions, Gen AI Class Tasks

## 📁 Files in this Repo
- `Assignment.ipynb` - Practice assignments
- `Dictionary.ipynb` - Dictionary notes
- `Error Handling.ipynb` - Try, Except, Finally
- `Functions.ipynb` - Functions concepts
- `If.Else.Elif.ipynb` - Conditional statements
- `List Set Tuple notes.ipynb` - Data structures
- `Interview.ipynb` - Interview prep codes

## 🛠️ Tools Used
- Python
- Jupyter Notebook
- VS Code

## 🚀 How to Use
Clone the repo and run notebooks in Jupyter.
